The problem it solves

Small businesses answer the same few questions all day: opening hours, prices, delivery. Messages also arrive after closing time, and an angry customer can sit unseen between routine questions.

SmartDesk handles the routine questions and puts the messages that need a person at the front.

What it does

Reads the business’s own documents
Plain text files for the FAQ, prices and policies. The owner can update them without a programmer.
Answers only from those documents
If the answer isn’t there, it says so and points the customer to the business phone number instead of guessing.
Sorts every message
Each message gets a category (question, order, complaint or other) and an urgency level of low, medium or high.
Flags what needs the owner
Complaints, refund disputes and anything the documents don’t cover are marked for a human to handle.

How it works

  1. A customer message comes inThe owner pastes it into the web page.
  2. The documents and rules are attachedThe assistant is told to use only the business’s documents and never to invent prices, hours or policies.
  3. Google’s Gemini model reads itIt fills in a fixed form: category, urgency, owner flag, reason and reply.
  4. The owner sees a clear resultGreen when it was handled automatically, red when a person is needed, with the reply ready to send.

Built to fail safely, and honest about its limits

Reliability

  • Shows a clear message if a setting or document is missing.
  • Retries when the AI service is busy, then flags the message for the owner.
  • Limits message length and replies per visit.
  • Keeps the API key out of the code and out of GitHub.

Limits

  • AI can make mistakes, which is why complaints and unusual requests go to a person.
  • It drafts replies but does not send them, and it cannot change prices or policies.
  • It works as a web page, not yet inside WhatsApp or a website chat.
  • Documents load as plain text, which suits small businesses with short documents.

Built with

Python, Google Gemini through the google-genai library, Pydantic for structured output, and Streamlit for the web interface. Hosted on Streamlit Community Cloud, with the code on GitHub.

SmartDesk was built as a project in the AI Masterclass 2 course. The demo uses a fictional business, Nakasero Phone Fix, and no real customer data.
